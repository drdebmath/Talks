§2The Mismatch

Can an Agent Open a Bank Account?

Identity

KYC assumes a person with a passport.

Hours

Bank settlement has business days. Agents don't.

Size

Fixed fees make sub-cent payments impossible.

Interface

Checkout pages, CAPTCHAs, OTPs — built for human eyes.

§3Fit

What an Agent Needs → What a Chain Gives

Agent needsOn-chain answer
Account, no paperworkA key pair is an account.
Money with an APIStablecoins (USDC, USDT …) as programmable tokens.
Tiny, instant paymentsL2 rollups: seconds, sub-cent.
Spending limitsSmart accounts (ERC-4337, EIP-7702): caps, allow-lists, session keys.
Trust strangersEscrow contracts + on-chain identity & reputation (ERC-8004).
Open 24/7, globalNo business days. No borders.
§3A 1997 Placeholder

HTTP 402: Payment Required

1997

HTTP/1.1 reserves 402 "for future use."

2025 · x402

Coinbase's open protocol finally uses it: pay inside the HTTP request.

Why agents like it

No account. No API key. No checkout page. One round trip.

Sources: RFC 2068 §10.4.3 | x402.org | github.com/coinbase/x402
